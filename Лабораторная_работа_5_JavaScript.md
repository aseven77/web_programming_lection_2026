## Задание 1. Переменные и вывод на страницу

### Шаг 1.1 — создаём файлы

Создайте два файла в одной папке: `task1.html` и `task1.js`.

В `task1.html` пропишите минимальную структуру страницы и подключите скрипт **в конце `<body>`** — это важно, чтобы к моменту выполнения JS-кода нужные элементы страницы уже существовали:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Задание 1</title>
</head>
<body>
    <p id="output"></p>

    <script src="task1.js"></script>
</body>
</html>
```

Обратите внимание на пустой абзац `<p id="output"></p>` — именно в него мы позже вставим текст с помощью JavaScript. Атрибут `id` — это «имя», по которому JavaScript найдёт этот элемент.

### Шаг 1.2 — объявляем переменные

В файле `task1.js` объявите две переменные:

```javascript
const name = "Азамат";
const group = "41-ПИ";
```

**Что это делает:** мы создаём две константы (`const` означает, что значение переменной менять больше нельзя). Замените значения на свои.

### Шаг 1.3 — собираем фразу через шаблонную строку

Добавьте в `task1.js`:

```javascript
const phrase = `Меня зовут ${name}, я учусь в группе ${group}`;
```

**Что это делает:** обратные кавычки `` ` `` создают «шаблонную строку» — внутри неё можно подставлять значения переменных прямо в текст через `${...}`. Результат — обычная строка: `"Меня зовут Азамат, я учусь в группе 41-ПИ"`.

### Шаг 1.4 — находим элемент на странице

```javascript
const output = document.getElementById("output");
```

**Что это делает:** `document` — это вся страница, представленная как объект. Метод `getElementById("output")` ищет на странице элемент с атрибутом `id="output"` — тот самый пустой абзац из Шага 1.1 — и сохраняет ссылку на него в переменную `output`.

### Шаг 1.5 — выводим текст на страницу

```javascript
output.textContent = phrase;
```

**Что это делает:** свойство `textContent` — это текст внутри элемента. Присваивая ему значение переменной `phrase`, мы заменяем пустое содержимое абзаца на нашу фразу.

### Шаг 1.6 — проверяем результат

Откройте `task1.html` в браузере. Вы должны увидеть на странице фразу с вашим именем и группой. Если ничего не появилось — откройте консоль браузера (`F12` → вкладка Console) и проверьте, нет ли ошибки.

## Задание 2. Кнопка и обработчик события

### Шаг 2.1 — размечаем страницу

Создайте `task2.html` и `task2.js`. В HTML добавьте кнопку и элемент для вывода счётчика:

```html
<button id="counterBtn">Нажми меня</button>
<p id="counter">Нажатий: 0</p>

<script src="task2.js"></script>
```

### Шаг 2.2 — заводим переменную-счётчик

```javascript
let count = 0;
```

**Что это делает:** мы объявляем переменную `count` через `let` (а не `const`), потому что её значение будет меняться при каждом нажатии на кнопку.

### Шаг 2.3 — находим кнопку и элемент счётчика

```javascript
const button = document.getElementById("counterBtn");
const counterText = document.getElementById("counter");
```

### Шаг 2.4 — подписываемся на событие клика

```javascript
button.addEventListener("click", function () {
    count = count + 1;
    counterText.textContent = "Нажатий: " + count;
});
```

**Что это делает построчно:**
- `addEventListener("click", ...)` говорит браузеру: «когда пользователь кликнет по этой кнопке, выполни следующую функцию».
- Функция внутри `addEventListener` не выполняется сразу — она сработает только в момент клика.
- `count = count + 1` увеличивает счётчик на единицу при каждом клике.
- `counterText.textContent = ...` обновляет текст на странице новым значением счётчика.

### Шаг 2.5 — проверяем результат

Откройте `task2.html`, нажмите на кнопку несколько раз и убедитесь, что число нажатий действительно увеличивается на странице.

## Задание 3. Массив новостей и методы `filter`/`map`

### Шаг 3.1 — готовим страницу

Создайте `task3.html` с пустым списком-контейнером и подключённым скриптом:

```html
<ul id="newsList"></ul>

<script src="task3.js"></script>
```

### Шаг 3.2 — объявляем массив новостей

В `task3.js`:

```javascript
const news = [
    { title: "Открылась новая библиотека", views: 120 },
    { title: "Итоги олимпиады по программированию", views: 340 },
    { title: "Расписание сессии обновлено", views: 980 },
    { title: "Встреча выпускников факультета", views: 75 },
];
```

**Что это такое:** массив из четырёх объектов. У каждого объекта два свойства — `title` (заголовок) и `views` (число просмотров), как в предыдущих лекциях про PHP, только теперь на JavaScript.

### Шаг 3.3 — отбираем популярные новости методом `filter`

```javascript
const popularNews = news.filter(function (item) {
    return item.views > 200;
});
```

**Что это делает:** `filter` проходит по каждому элементу массива `news` и **оставляет только те**, для которых функция внутри вернула `true`. Здесь мы оставляем новости, у которых `views` больше 200. Результат — новый массив `popularNews`, короче исходного.

Проверьте себя: выведите `popularNews` в консоль командой `console.log(popularNews)` и посмотрите, сколько новостей осталось.

### Шаг 3.4 — превращаем объекты в строки методом `map`

```javascript
const newsStrings = popularNews.map(function (item) {
    return item.title + " (" + item.views + " просмотров)";
});
```

**Что это делает:** `map` тоже проходит по каждому элементу массива, но не отбирает, а **преобразует** каждый элемент во что-то новое — в данном случае из объекта `{title, views}` получаем обычную строку. Результат — новый массив строк, той же длины, что и `popularNews`.

### Шаг 3.5 — выводим список на страницу

```javascript
const list = document.getElementById("newsList");

for (const text of newsStrings) {
    const li = document.createElement("li");
    li.textContent = text;
    list.appendChild(li);
}
```

**Что это делает построчно:**
- `document.createElement("li")` создаёт новый, пока «пустой» и невидимый HTML-элемент `<li>`.
- `li.textContent = text` кладёт внутрь этого элемента нужный текст.
- `list.appendChild(li)` добавляет готовый элемент `<li>` внутрь списка `<ul id="newsList">` на странице — только после этого он становится видимым.
- Цикл `for...of` повторяет эти три действия для каждой строки из массива `newsStrings`.

### Шаг 3.6 — проверяем результат

Откройте `task3.html` — должен появиться список только из «популярных» новостей (просмотров больше 200), в формате «Заголовок (число просмотров)».

## Задание 4. Загрузка данных с сервера через `fetch`

### Шаг 4.1 — размечаем страницу

Создайте `task4.html`:

```html
<button id="loadBtn">Загрузить данные</button>
<div id="result"></div>

<script src="task4.js"></script>
```

### Шаг 4.2 — находим кнопку и контейнер результата

```javascript
const loadBtn = document.getElementById("loadBtn");
const result = document.getElementById("result");
```

### Шаг 4.3 — пишем асинхронную функцию загрузки данных

```javascript
async function loadData() {
    try {
        const response = await fetch("https://jsonplaceholder.typicode.com/posts");
        const data = await response.json();

        result.textContent = "";

        for (const post of data) {
            const p = document.createElement("p");
            p.textContent = post.title;
            result.appendChild(p);
        }

    } catch (error) {
        result.textContent = "Не удалось загрузить данные";
    }
}
```

**Что это делает построчно:**
- Слово `async` перед функцией разрешает использовать внутри неё `await` — «подожди, пока это действие закончится, прежде чем выполнять следующую строку».
- `fetch(...)` отправляет запрос к серверу — это долгая операция (нужно время, чтобы получить ответ по сети), поэтому мы пишем `await fetch(...)`, чтобы дождаться результата.
- `response.json()` тоже требует времени — он превращает «сырой» ответ сервера в обычный JavaScript-массив/объект, поэтому здесь тоже стоит `await`.
- `result.textContent = ""` очищает контейнер результата перед новой загрузкой — иначе при повторном нажатии кнопки новости будут добавляться друг под другом бесконечно.
- Цикл `for...of` перебирает полученные данные так же, как в Задании 3, и добавляет каждую запись на страницу отдельным абзацем `<p>`.
- Блок `try { ... } catch (error) { ... }`: код внутри `try` выполняется в обычном режиме, но если на любом шаге произойдёт ошибка (например, нет интернета или сервер недоступен) — вместо падения всего скрипта выполнится код внутри `catch`, и пользователь увидит понятное сообщение.

### Шаг 4.4 — вызываем функцию по клику на кнопку

```javascript
loadBtn.addEventListener("click", loadData);
```

**Что это делает:** мы говорим браузеру — «при клике на кнопку `loadBtn` вызови функцию `loadData`», которую мы написали в Шаге 4.3. Заметьте: здесь мы передаём саму функцию `loadData` (без скобок), а не вызываем её сразу.

### Шаг 4.5 — проверяем результат

Откройте `task4.html`, нажмите кнопку «Загрузить данные» — на странице должны появиться заголовки нескольких тестовых постов. Попробуйте отключить интернет и нажать кнопку ещё раз — должно появиться сообщение «Не удалось загрузить данные».

### Шаг 4.6 (по желанию) — используем свой `api.php`

Если у вас уже готов `api.php` из предыдущих лабораторных работ, замените адрес в `fetch(...)` на адрес вашего локального скрипта, например:

```javascript
const response = await fetch("http://localhost/api.php");
```

и убедитесь, что данные с вашего собственного сервера так же успешно выводятся на странице.
