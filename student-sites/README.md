# Пять HTML-сайтов для интеграции PHP

Начните с [index.html](index.html). Индивидуальные задания: [assignments.html](assignments.html) и [assignments.md](assignments.md). Общие требования: [requirements.md](requirements.md).

20 вариантов для распределения между студентами, по четыре на сайт. В каждом варианте 20 последовательных заданий с проверками (400 пунктов суммарно). Отдельные файлы для выдачи: variants/variant-01…20.html и .md.

Каждая папка сайта самостоятельна: 10 страниц интерфейса, styles.css, README.html/.md. Скопируйте её целиком и откройте index.html. Формы отключены, серверную логику и JavaScript/fetch пишут студенты. detail.html — образец первой записи независимо от id.

При интеграции переименуйте страницы в .php, исправьте href/action и замените поле заготовки полем своего варианта. Используется учебный подход $pdo; имя таблицы news меняется согласно предметной области. Материалы основаны на текущих лабораторных №1–13, включая регистрацию, вход и права.

Проверка ссылок: node scripts/check.mjs. Результат и ограничения: [VALIDATION.md](VALIDATION.md). Комплект добавлен в html/index.html курса.

## Самостоятельность студентов

Правила самостоятельной работы и контрольные точки: [requirements.md](requirements.md). Памятка преподавателю: [teacher-guide.md](teacher-guide.md). Во всех 20 вариантах добавлены самостоятельные действия к каждому пункту и своя особенность в пункте 4. Очная защита составляет 20 баллов из 100.
