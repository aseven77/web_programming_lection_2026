# Лабораторная работа №1

## Дисциплина: Web-программирование
## Тема: Клиент-серверная архитектура и HTTP-протокол

---

## Цель работы

Закрепить на практике понимание клиент-серверного взаимодействия: научиться анализировать HTTP-запросы и ответы в браузере, выполнять запросы к REST API вручную и с помощью инструментов, различать типы веб-приложений и методы/коды состояния HTTP.

## Необходимые инструменты

- Браузер Google Chrome или Mozilla Firefox (инструменты разработчика).
- Postman **или** расширение Thunder Client для VS Code **или** утилита `curl` в терминале.
- Доступ в Интернет.

---

## Задание 1. Анализ HTTP-запросов в браузере

1. Откройте любой сайт (например, новостной портал или интернет-магазин).
2. Откройте инструменты разработчика (клавиша `F12` или правый клик → «Просмотреть код») и перейдите на вкладку **Network (Сеть)**.
3. Обновите страницу и найдите в списке запросов:
   - основной **document**-запрос (сама HTML-страница);
   - минимум один запрос типа **XHR/Fetch** (запрос к API, вернувший JSON).
4. Для каждого из двух запросов зафиксируйте в отчёте:
   - метод запроса (GET/POST/…);
   - код состояния ответа;
   - значение заголовка `Content-Type` в ответе;
   - размер ответа и время выполнения запроса.
5. Сделайте и вставьте в отчёт скриншот вкладки Network с выделенными запросами.

**Вопрос для отчёта:** чем отличается document-запрос от XHR/Fetch-запроса по содержимому и по назначению?

## Задание 2. Выполнение запросов к публичному REST API

Используйте бесплатный тестовый API **JSONPlaceholder** (`https://jsonplaceholder.typicode.com`) или **OpenWeatherMap** (потребуется бесплатный API-ключ).

Выполните следующие запросы любым из инструментов (Postman, Thunder Client или `curl`) и приложите в отчёт скриншоты запроса и ответа для каждого пункта:

1. **GET-запрос** на получение списка постов: `GET https://jsonplaceholder.typicode.com/posts`.
2. **GET-запрос** с параметром на получение одного конкретного поста: `GET https://jsonplaceholder.typicode.com/posts/1`.
3. **POST-запрос** на создание нового ресурса — отправьте в теле запроса JSON вида:
   ```json
   {
     "title": "Моя лабораторная работа",
     "body": "Текст поста",
     "userId": 1
   }
   ```
4. **DELETE-запрос** на удаление ресурса: `DELETE https://jsonplaceholder.typicode.com/posts/1`.

Для каждого запроса укажите в отчёте: полученный код состояния и одно-два предложения — что означает этот код.

## Задание 3. Работа с `curl` из командной строки

Выполните в терминале следующую команду и вставьте в отчёт и команду, и полученный ответ:

```bash
curl -i https://jsonplaceholder.typicode.com/users/1
```

Флаг `-i` выводит вместе с телом ответа и HTTP-заголовки. В отчёте укажите:
- код состояния ответа;
- значение заголовка `Content-Type`;
- какие поля содержатся в теле ответа (перечислите ключи JSON-объекта).

## Задание 4. Классификация веб-приложений

Выберите три знакомых вам сайта/сервиса (например: почтовый сервис, интернет-магазин, новостной портал) и для каждого определите, к какому типу приложений он ближе всего — **MPA, SPA, SSR или PWA**. Обоснуйте выбор (1–2 предложения на каждый сервис), опираясь на наблюдаемое поведение: перезагружается ли страница при переходах, предлагает ли сайт «установку» на устройство и т. п.
