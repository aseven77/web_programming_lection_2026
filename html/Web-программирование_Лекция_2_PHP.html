Web-программирование. Лекция 2

PHP: основы серверного программирования

1. Зачем нужен PHP

В первой лекции мы рассмотрели, что backend-часть веб-приложения отвечает за логику, недоступную пользователю напрямую: обработку запросов, работу с базой данных, формирование ответа клиенту. PHP (PHP: Hypertext Preprocessor) — один из самых распространённых языков для написания именно такой серверной логики.

Особенности PHP:

  • Интерпретируемый язык — код выполняется построчно на сервере в момент запроса, без предварительной компиляции.
  • Изначально заточен под веб — встроены готовые механизмы для работы с HTTP-запросами, сессиями, формами, файлами.
  • Свободно распространяется — обработчик PHP бесплатен и установлен на подавляющем большинстве хостингов.
  • Огромная экосистема — от небольших скриптов до крупных фреймворков (Laravel, Symfony) и таких проектов, как WordPress.

PHP-код выполняется на сервере, и клиенту (браузеру) отправляется уже готовый результат — HTML-страница или JSON-данные, а не сам код PHP. Файл со сценарием обязательно должен иметь расширение .php — иначе веб-сервер посчитает его обычной статической страницей и не станет выполнять.

2. Как PHP-скрипт встраивается в страницу

PHP-код размещается внутри специальных тегов <?php ... ?> и может свободно чередоваться с обычной HTML-разметкой: 

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Пример PHP-страницы</title>
</head>
<body>
    <h1>
        <?php
            echo "Привет, мир!";
        ?>
    </h1>
</body>
</html>

Когда браузер запрашивает такую страницу, веб-сервер (например, Nginx с PHP-FPM) выполняет код между <?php и ?>, а клиенту отправляет уже готовый HTML — код PHP пользователю никогда не виден.

3. Переменные, типы данных и операторы

Переменные

Переменные в PHP всегда начинаются со знака $, тип указывать не нужно — PHP определяет его автоматически: 

<?php
$name = "Азамат";
$age = 30;
$isStudent = false;
$price = 199.99;

Основные типы данных

Тип Описание Пример
string Строка "Привет"
int Целое число 42
float Число с плавающей точкой 3.14
bool Логическое значение true, false
array Массив [1, 2, 3]
null Отсутствие значения null

Операторы

<?php
$sum = 5 + 3;        // арифметические: + - * / % **
$isEqual = (5 == "5");   // нестрогое сравнение — true
$isIdentical = (5 === "5"); // строгое сравнение (тип + значение) — false
$result = true && false; // логические: && || !
$greeting = "Привет, " . $name; // конкатенация строк через точку

Важно: оператор == сравнивает только значения (с приведением типов), а === — значения и типы одновременно. В современном PHP рекомендуется использовать строгое сравнение ===, чтобы избежать неожиданного поведения при сравнении разных типов.

4. Массивы

Массивы в PHP бывают индексными (числовые ключи) и ассоциативными (ключи-строки): 

<?php
// Индексный массив
$fruits = ["яблоко", "банан", "груша"];
echo $fruits[0]; // яблоко

// Ассоциативный массив
$user = [
    "name" => "Азамат",
    "role" => "преподаватель",
    "city" => "Уфа"
];
echo $user["name"]; // Азамат

// Перебор массива
foreach ($fruits as $fruit) {
    echo $fruit . "\n";
}

foreach ($user as $key => $value) {
    echo "$key: $value\n";
}

5. Условные конструкции и циклы

<?php
$age = 20;

if ($age >= 18) {
    echo "Совершеннолетний";
} elseif ($age >= 14) {
    echo "Подросток";
} else {
    echo "Ребёнок";
}

// Цикл for
for ($i = 0; $i < 5; $i++) {
    echo $i;
}

// Цикл while
$i = 0;
while ($i < 5) {
    echo $i;
    $i++;
}

6. Функции

<?php
function greet(string $name): string {
    return "Здравствуйте, $name!";
}

echo greet("Мир"); // Здравствуйте, Мир!

Начиная с PHP 7, поддерживается строгая типизация параметров и возвращаемого значения (string, int, array и т. д.), что делает код надёжнее и облегчает поиск ошибок ещё до выполнения скрипта.

7. Получение данных от клиента

Ключевая задача серверного скрипта — обработать данные, присланные пользователем. PHP предоставляет для этого суперглобальные массивы:

Суперглобальный массив Что содержит
$_GET Параметры из строки запроса (?key=value)
$_POST Данные, отправленные методом POST (например, из формы)
$_REQUEST Объединение $_GET, $_POST и $_COOKIE
$_SERVER Информация о сервере и запросе (метод, адрес, заголовки)
$_SESSION Данные текущей сессии пользователя
$_COOKIE Cookie, полученные от браузера
$_FILES Загруженные пользователем файлы

Пример обработки простой формы:

<form action="process.php" method="post">
    <input type="text" name="username">
    <button type="submit">Отправить</button>
</form>

<?php
// process.php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $username = htmlspecialchars($_POST["username"] ?? "");
    echo "Здравствуйте, $username!";
}

Обратите внимание на htmlspecialchars() — экранирование пользовательского ввода перед выводом обязательно, иначе приложение уязвимо к XSS-атакам (внедрению постороннего HTML/JS-кода через данные пользователя).

8. PHP как обработчик REST API

В первой лекции говорилось, что современные приложения обмениваются данными в формате JSON через REST API. PHP отлично подходит для написания такого API: 

<?php
header("Content-Type: application/json; charset=utf-8");

$data = [
    "city" => "Moscow",
    "temperature" => 5,
    "condition" => "cloudy"
];

echo json_encode($data, JSON_UNESCAPED_UNICODE);

Ответ, который получит клиент:

{"city":"Moscow","temperature":5,"condition":"cloudy"}

Для чтения тела JSON-запроса (например, при POST-запросе от SPA-приложения на Vue или React) используется: 

<?php
$input = json_decode(file_get_contents("php://input"), true);
$name = $input["name"] ?? null;

9. Работа с базой данных: PDO

Для взаимодействия с базой данных (MySQL, PostgreSQL) современный PHP использует расширение PDO (PHP Data Objects) — единый интерфейс для разных СУБД с поддержкой подготовленных выражений (prepared statements), которые защищают от SQL-инъекций. 

<?php
$pdo = new PDO("mysql:host=localhost;dbname=shop;charset=utf8mb4", "user", "password");

// Подготовленное выражение — безопасная подстановка параметров
$stmt = $pdo->prepare("SELECT * FROM products WHERE category = :category");
$stmt->execute(["category" => "electronics"]);

$products = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($products as $product) {
    echo $product["name"] . "\n";
}

Никогда не подставляйте пользовательский ввод напрямую в SQL-запрос через конкатенацию строк — это классическая уязвимость SQL-инъекции. Именованные параметры (:category) в PDO решают эту проблему автоматически.

10. От отдельных скриптов к современному PHP

Исторически PHP-приложения писались как набор отдельных .php-файлов, обрабатывающих запросы напрямую. Современная разработка на PHP устроена иначе:

  • Composer — менеджер пакетов PHP (аналог npm для JavaScript), через него подключаются готовые библиотеки.
  • Фреймворки — Laravel, Symfony — задают структуру проекта, берут на себя маршрутизацию, работу с базой данных через ORM, шаблонизацию и безопасность.
  • MVC-архитектура (Model — View — Controller) — разделение кода на модель данных, представление и логику обработки запроса, что упрощает поддержку крупных проектов.
  • Composer autoload + namespace — организация кода по классам и пространствам имён вместо набора разрозненных файлов.
  • PSR-стандарты (PHP Standards Recommendations) — единые соглашения по стилю кода и структуре, которых придерживается всё современное PHP-сообщество.

Актуальные версии языка (PHP 8.x) значительно отличаются от PHP 5–7: добавлены строгая типизация, именованные аргументы, enum-типы, улучшенная производительность движка (JIT-компиляция).

11. Итоги

  1. PHP — интерпретируемый серверный язык, изначально созданный для веба: код выполняется на сервере, клиенту отправляется готовый HTML или JSON.
  2. Базовые конструкции — переменные ($имя), типы данных, массивы (индексные и ассоциативные), условия, циклы и функции — синтаксически близки к другим C-подобным языкам.
  3. Данные от клиента PHP получает через суперглобальные массивы $_GET, $_POST, $_SERVER и т. д.; пользовательский ввод обязательно нужно экранировать перед выводом.
  4. PHP может выступать как обработчик классических форм, так и как backend для REST API, отдающий JSON современным SPA-приложениям на Vue или React.
  5. Для работы с базой данных используется PDO с подготовленными выражениями — это защищает от SQL-инъекций.
  6. Современная разработка на PHP строится вокруг Composer, фреймворков (Laravel, Symfony) и архитектуры MVC, а не отдельных изолированных скриптов.
