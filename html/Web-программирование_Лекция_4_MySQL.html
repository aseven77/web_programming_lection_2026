Web-программирование. Лекция 4

MySQL: подключаем сайт к базе данных

1. От массива в коде — к базе данных

В прошлой лекции лента новостей хранилась прямо в PHP-коде:

<?php
$news = [
    ["title" => "Открылась новая библиотека", "views" => 120],
    ["title" => "Итоги олимпиады по программированию", "views" => 340],
];

У такого подхода есть большая проблема: чтобы добавить новость, нужно вручную редактировать код. Данные исчезают, если их явно не сохранить в файл. Несколько человек не могут одновременно и безопасно их редактировать.

Решение — хранить данные в базе данных, а PHP-скрипт будет каждый раз забирать из неё актуальный список и выводить его точно так же, как раньше выводил обычный массив.

2. MySQL и таблицы

MySQL — система управления базами данных (СУБД), которая хранит данные в виде таблиц: строки — это записи (например, одна новость), столбцы — поля записи (заголовок, текст, дата).

Создадим таблицу для новостей:

CREATE TABLE news (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

И таблицу для контактов:

CREATE TABLE contacts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    label VARCHAR(50) NOT NULL,
    value VARCHAR(255) NOT NULL
);

Здесь label — это название контакта («Телефон», «Email», «Адрес»), а value — его значение.

Добавим тестовые данные:

INSERT INTO news (title, content) VALUES
('Открылась новая библиотека', 'В университете открылась новая библиотека с читальным залом.'),
('Итоги олимпиады по программированию', 'Наши студенты заняли первое место в региональной олимпиаде.');

INSERT INTO contacts (label, value) VALUES
('Телефон', '+7 (347) 123-45-67'),
('Email', 'info@example.ru'),
('Адрес', 'г. Уфа, ул. Университетская, 1');

3. Подключение к базе данных из PHP

Для связи PHP с MySQL используется расширение PDO. Подключение обычно выносят в отдельный файл, чтобы не дублировать код на каждой странице: 

<?php
// config.php
$pdo = new PDO(
    "mysql:host=localhost;dbname=site;charset=utf8mb4",
    "root",
    "",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

На любой странице сайта достаточно подключить этот файл:

<?php
require "config.php";

4. Читаем новости из базы данных

Раньше мы перебирали обычный PHP-массив циклом foreach. Теперь вместо массива, объявленного вручную, мы получаем его из базы данных — а сам цикл вывода остаётся точно таким же: 

<?php
require "config.php";

$stmt = $pdo->query("SELECT * FROM news ORDER BY created_at DESC");
$news = $stmt->fetchAll(PDO::FETCH_ASSOC);

<ul>
    <?php foreach ($news as $item): ?>
        <li>
            <strong><?= htmlspecialchars($item["title"]) ?></strong>
            <p><?= htmlspecialchars($item["content"]) ?></p>
        </li>
    <?php endforeach; ?>
</ul>

Обратите внимание: мы снова используем htmlspecialchars(), чтобы данные из базы безопасно выводились на странице, даже если в них случайно окажутся специальные символы.

5. Читаем контакты из базы данных

Точно так же поступаем со страницей контактов:

<?php
require "config.php";

$stmt = $pdo->query("SELECT * FROM contacts");
$contacts = $stmt->fetchAll(PDO::FETCH_ASSOC);

<ul>
    <?php foreach ($contacts as $contact): ?>
        <li><strong><?= htmlspecialchars($contact["label"]) ?>:</strong> <?= htmlspecialchars($contact["value"]) ?></li>
    <?php endforeach; ?>
</ul>

6. Один файл подключения — много страниц

Главная идея сегодняшней лекции: у сайта может быть сколько угодно страниц (index.php, news.php, contacts.php), но подключение к базе данных настраивается один раз в config.php и переиспользуется везде. Меняется только SQL-запрос — под то, какие данные нужны конкретной странице. 

project/
├── config.php     ← подключение к БД (один раз)
├── index.php      ← главная страница
├── news.php       ← новости из таблицы news
└── contacts.php   ← контакты из таблицы contacts

7. Итоги

  1. Хранить данные в MySQL удобнее, чем прямо в коде: их можно редактировать без изменения PHP-файлов, и они не теряются при перезапуске сервера.
  2. Подключение к базе данных настраивается один раз через PDO и подключается на каждой странице сайта через require.
  3. Чтение данных из базы (SELECT + fetchAll) даёт точно такой же массив, с каким мы уже работали в цикле foreach — вывод на странице не меняется.
  4. Реальный сайт обычно состоит из нескольких PHP-страниц, использующих одно общее подключение к базе данных и разные SQL-запросы.
  5. Данные, полученные из базы, перед выводом на страницу всегда нужно обрабатывать функцией htmlspecialchars().
