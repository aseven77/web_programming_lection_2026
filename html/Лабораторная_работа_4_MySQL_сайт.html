Лабораторная работа №4

Дисциплина: Web-программирование

Тема: Подключение сайта к базе данных MySQL

Цель работы

Взять готовый статичный сайт из трёх страниц (Главная, Новости, Контакты) и превратить его в динамический PHP-сайт, который хранит новости и контакты не в коде, а в базе данных MySQL.

Необходимые инструменты

  • Локальный сервер с поддержкой PHP и MySQL: XAMPP или Open Server.
  • phpMyAdmin (входит в состав XAMPP/Open Server) — для создания базы данных через интерфейс.
  • Текстовый редактор или IDE (VS Code, PhpStorm).
  • Браузер.

Этап 1. Готовим статичный сайт (HTML)

Если у вас ещё нет готового сайта из предыдущих занятий — создайте три простых HTML-файла с общим меню-навигацией:

  • index.html — главная страница с приветственным текстом.
  • news.html — страница со списком из 3–4 новостей, оформленных вручную прямо в HTML (заголовок + короткий текст каждой новости).
  • contacts.html — страница с контактами (телефон, email, адрес), также прописанными вручную в HTML.

На каждой странице должно быть одинаковое меню со ссылками на все три страницы. Пример меню: 

<nav>
    <a href="index.html">Главная</a>
    <a href="news.html">Новости</a>
    <a href="contacts.html">Контакты</a>
</nav>

Откройте сайт в браузере и убедитесь, что переключение между страницами работает.

Этап 2. Создаём базу данных

  1. Откройте phpMyAdmin и создайте новую базу данных с именем site.
  2. Внутри базы данных выполните SQL-запрос для создания таблицы новостей:
CREATE TABLE news (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
  1. Создайте таблицу контактов:
CREATE TABLE contacts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    label VARCHAR(50) NOT NULL,
    value VARCHAR(255) NOT NULL
);
  1. Заполните обе таблицы своими данными (минимум 4 новости и 3 контакта) — либо через SQL-запросы INSERT, либо вручную через интерфейс phpMyAdmin (вкладка «Вставить»).

Приложите к отчёту скриншот структуры обеих таблиц и их содержимого из phpMyAdmin.

Этап 3. Подключение к базе данных

  1. Переименуйте все три файла сайта: index.html → index.php, news.html → news.php, contacts.html → contacts.php.
  2. Создайте файл config.php с подключением к базе данных через PDO: 
<?php
$pdo = new PDO(
    "mysql:host=localhost;dbname=site;charset=utf8mb4",
    "root",
    "",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);
  1. В начале каждого из трёх .php-файлов подключите config.php: 
<?php require "config.php"; ?>

Этап 4. Страница «Новости» — вывод из базы данных

  1. В news.php замените новости, прописанные вручную в HTML, на код, который получает их из базы данных: 
<?php
require "config.php";
$stmt = $pdo->query("SELECT * FROM news ORDER BY created_at DESC");
$news = $stmt->fetchAll(PDO::FETCH_ASSOC);
?>
  1. Выведите список новостей циклом foreach, используя htmlspecialchars() для безопасного вывода: 
<?php foreach ($news as $item): ?>
    <div class="news-item">
        <h3><?= htmlspecialchars($item["title"]) ?></h3>
        <p><?= htmlspecialchars($item["content"]) ?></p>
    </div>
<?php endforeach; ?>
  1. Проверьте страницу в браузере — новости должны отображаться так же, как раньше, но теперь их источник — база данных.

Этап 5. Страница «Контакты» — вывод из базы данных

Аналогично Этапу 4, замените контакты, прописанные вручную в contacts.php, на данные из таблицы contacts: 

<?php
require "config.php";
$stmt = $pdo->query("SELECT * FROM contacts");
$contacts = $stmt->fetchAll(PDO::FETCH_ASSOC);
?>

<ul>
    <?php foreach ($contacts as $contact): ?>
        <li><strong><?= htmlspecialchars($contact["label"]) ?>:</strong> <?= htmlspecialchars($contact["value"]) ?></li>
    <?php endforeach; ?>
</ul>

Этап 6. Проверка результата

  1. Добавьте через phpMyAdmin ещё одну новость в таблицу news, не трогая PHP-код сайта.
  2. Обновите страницу news.php в браузере и убедитесь, что новая новость появилась автоматически — без изменения кода.
  3. Сделайте то же самое с одним контактом в таблице contacts и проверьте contacts.php.

Приложите к отчёту скриншоты страниц news.php и contacts.php до и после добавления новых данных через phpMyAdmin.

Задание со звёздочкой (необязательное)

На главной странице index.php выведите 3 последние новости (используйте в SQL-запросе ORDER BY created_at DESC LIMIT 3) в виде короткого анонса — так часто устроена главная страница настоящих сайтов.

Требования к оформлению отчёта

Отчёт оформляется в виде документа (.docx или .pdf) и должен содержать:

  1. Титульный лист: ФИО студента, группа, тема лабораторной работы.
  2. Скриншот структуры и содержимого таблиц news и contacts из phpMyAdmin.
  3. Листинги кода config.php, news.php, contacts.php.
  4. Скриншоты страниц news.php и contacts.php до и после добавления новых данных через базу данных.
  5. Краткий вывод по работе (2–3 предложения).

Также к отчёту прикладывается архив с исходными файлами сайта (.php-файлы и файл экспорта базы данных .sql из phpMyAdmin).

  2. Что делает метод fetchAll(PDO::FETCH_ASSOC)?
  3. Почему после добавления новости через phpMyAdmin не нужно менять код news.php?
  4. Зачем при выводе данных из базы использовать htmlspecialchars()?
  5. Чем отличается статичный HTML-сайт от такого же сайта на PHP с базой данных?
