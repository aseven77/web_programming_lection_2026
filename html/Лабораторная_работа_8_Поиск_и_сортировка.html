Что должно получиться

Создадим страницу news-search.php с полем поиска, выбором порядка и кнопкой «Найти». После отправки формы страница перезагрузится и покажет подходящие новости. Например, по слову «Кружок» будут найдены заголовки «Кружок рисования» и «Кружок робототехники».

Сначала соберём страницу маленькими шагами, затем проверим и немного дополним самостоятельно. Писать по памяти не требуется.

Используем базу site, таблицу news и config.php, создающий $pdo. Достаточно вспомнить формы, foreach и чтение базы. Дополнительные задания лабораторной №7 не требуются.

Перед началом: проверяем место работы

Понадобятся PHP 8, MySQL, расширения pdo_mysql и mbstring, редактор и браузер. Если рабочей базы или config.php ещё нет, выполните задание 1 лабораторной №6. Затем вернитесь сюда.

  1. Запустите свой локальный сервер и MySQL.
  2. Откройте ранее работавшую страницу admin.php или news.php через локальный сайт.
  3. Убедитесь, что новости читаются без ошибки подключения.
  4. В phpMyAdmin выберите базу site, таблицу news, вкладку «Структура». Нужны поля id, title, content, created_at.
  5. Рядом с config.php создайте новый пустой файл news-search.php. Сохраните его в UTF-8 без BOM.

Шаг 2. Собрать один файл из четырёх блоков

Ниже четыре блока для одного news-search.php. Копируйте их подряд. Пустые строки между блоками допустимы; пояснения и значки ``` в файл не копируем.

Первый блок открывает PHP через <?php. Второй продолжает PHP и закрывает его через ?>. Третий и четвёртый содержат HTML с небольшими PHP-вставками. Не добавляйте свои открывающие или закрывающие теги между блоками.

Страницу проверяем после всех четырёх блоков.

Блок 1 из 4. Получить и проверить условия

Это начало файла. Перед <?php не должно быть текста или пустой строки. 

<?php
ini_set('display_errors', '0');
header('Content-Type: text/html; charset=utf-8');

function e(string $value): string {
    return htmlspecialchars($value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

$errors = [];
$news = [];
$q = '';
$sort = 'new';
$orders = [
    'new' => 'id DESC',
    'old' => 'id ASC',
];

$rawQ = $_GET['q'] ?? '';
$rawSort = $_GET['sort'] ?? 'new';

if (!is_string($rawQ)) {
    $errors[] = 'Поисковый запрос должен быть строкой.';
} elseif (!mb_check_encoding($rawQ, 'UTF-8')) {
    $errors[] = 'Введите поисковый запрос в кодировке UTF-8.';
} else {
    $q = trim($rawQ);
    if (mb_strlen($q, 'UTF-8') > 100) {
        $errors[] = 'Поисковый запрос должен быть не длиннее 100 символов.';
    }
}

if (!is_string($rawSort) || !isset($orders[$rawSort])) {
    $errors[] = 'Неизвестный порядок. Выберите «Сначала новые» или «Сначала старые».';
} else {
    $sort = $rawSort;
}

if ($errors) {
    http_response_code(400);
}

Разберём небольшими частями:

  • header() сообщает браузеру, что ответ — HTML в UTF-8. Заголовки отправляются до самого HTML.
  • e() пригодится при выводе текста в HTML. Сейчас функция только объявлена.
  • $errors — список сообщений об ошибках. Пока список пуст, всё идёт нормально.
  • $news — будущий список новостей. Начинаем с пустого массива.
  • $orders — два разрешённых варианта SQL-порядка. Посетитель не сможет добавить третий вариант через адрес.
  • $_GET['q'] ?? '' читает q, а при отсутствии параметра берёт пустую строку. Для sort значение по умолчанию — new.
  • is_string() проверяет тип. mb_check_encoding() проверяет UTF-8. Только затем можно обрабатывать запрос как текст.
  • trim() убирает пробелы по краям. mb_strlen() считает символы; лимит 100 проверяется уже после trim().
  • isset($orders[$rawSort]) проверяет наличие выбора в разрешённом списке. Условие после || проверяется лишь тогда, когда значение уже является строкой.
  • http_response_code(400) устанавливает статус неверного запроса. Текст ошибки будет показан позже, в третьем блоке.

При неверном порядке $sort остаётся равной new для отображения формы; сам поиск не запускается.

display_errors отключает служебные подробности PHP на странице: их смотрим в журнале сервера. Посетителю покажем свои понятные сообщения.

Проверьте себя: при ?q=Кружок&sort=old переменные $q и $sort равны Кружок и old. Без параметров — пустая строка и new.

Блок 2 из 4. Прочитать подходящие новости

Добавьте сразу после блока 1. Новый <?php здесь не нужен: PHP уже открыт. 

if (!$errors) {
    try {
        require __DIR__ . '/config.php';

        $sql = 'SELECT id, title, content, created_at FROM news';
        $params = [];

        if ($q !== '') {
            $sql .= ' WHERE title LIKE :q';
            $params['q'] = '%' . $q . '%';
        }

        $sql .= ' ORDER BY ' . $orders[$sort];
        $stmt = $pdo->prepare($sql);
        $stmt->execute($params);
        $news = $stmt->fetchAll(PDO::FETCH_ASSOC);
    } catch (Throwable $error) {
        error_log((string) $error);
        http_response_code(500);
        $errors[] = 'Не удалось загрузить новости. Проверьте сервер и подключение к базе.';
    }
}
?>

Что происходит:

  1. if (!$errors) означает «работай, только если ошибок нет». При неверном вводе до базы дело не дойдёт.
  2. require подключает готовый config.php; __DIR__ обозначает папку текущего файла.
  3. $sql начинается с команды чтения всех новостей. $params пока пуст, потому что значений для подстановки ещё нет.
  4. Если строка поиска непустая, добавляем условие WHERE title LIKE :q и кладём шаблон в $params['q'].
  5. Если строка пустая, условие не добавляется: запрос прочитает все новости.
  6. Дописываем только проверенный порядок из $orders.
  7. prepare() готовит запрос; execute() передаёт значения; fetchAll(PDO::FETCH_ASSOC) получает массив записей с именованными полями.
  8. Если база недоступна или запрос выполнить не удалось, catch записывает подробности в журнал и устанавливает статус 500. На страницу попадёт понятная общая ошибка.

Для слова «Кружок» передаваемый шаблон равен %Кружок%. Первый % допускает любой текст перед словом, второй — после него. Знак _ тоже специальный: это один любой символ. Мы сохраняем такое поведение, поэтому поиск % показывает все строки с заголовками. Это не буквальный поиск символа процента. Правила есть в документации MySQL.

Пробелы перед WHERE и ORDER BY отделяют части SQL. :q пишем без кавычек; шаблон передаём целиком через execute(). Подробнее: параметры PDO.

Контрольная остановка 2. Найдите три переменные: $sql хранит инструкцию, $params — значения для неё, $news — полученные записи. Подпишите их комментариями, если пока путаетесь.

Блок 3 из 4. Показать форму и ошибки

Добавьте после ?> из блока 2. Здесь начинается обычный HTML.

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Поиск новостей</title>
</head>
<body>
<h1>Поиск новостей</h1>
<p>Ищем только в заголовках. Пустое поле покажет все новости.</p>

<form method="get" action="news-search.php">
    <p>
        <label for="q">Слово или часть заголовка</label>
        <input id="q" name="q" maxlength="100" value="<?= e($q) ?>">
    </p>
    <p>
        <label for="sort">Порядок</label>
        <select id="sort" name="sort">
            <option value="new" <?= $sort === 'new' ? 'selected' : '' ?>>Сначала новые</option>
            <option value="old" <?= $sort === 'old' ? 'selected' : '' ?>>Сначала старые</option>
        </select>
    </p>
    <button type="submit">Найти</button>
    <a href="news-search.php">Сбросить условия</a>
</form>

<?php foreach ($errors as $error): ?>
    <p role="alert"><?= e($error) ?></p>
<?php endforeach; ?>

Разбираем форму:

  • method="get" отправляет условия в адресе. action указывает на наш же файл.
  • У каждого поля есть name: без него значение не попадёт в запрос.
  • value="<?= e($q) ?>" возвращает слово в поле после перезагрузки. Короткая запись <?= ... ?> означает «выведи результат выражения».
  • e() применяется и к слову поиска, и к сообщениям. Она переводит специальные HTML-символы в безопасное текстовое представление.
  • Выражение $sort === 'old' ? 'selected' : '' читаем так: «если выбран old, выведи атрибут selected, иначе выведи пустую строку».
  • Ссылка сброса не содержит ?q=...: при её открытии PHP возьмёт значения по умолчанию.
  • foreach выводит каждое сообщение из $errors. Пустой массив не создаст ни одного сообщения.

Не добавляем required к поиску: пустое поле разрешено. Выбор порядка применяется после нажатия «Найти», а не сразу при смене значения в списке.

Блок 4 из 4. Показать список и закончить страницу

Добавьте после блока 3. В этом блоке уже есть все необходимые PHP-теги и закрывающие HTML-теги. 

<?php if (!$errors): ?>
    <h2>Результаты</h2>
    <p>Найдено новостей: <?= count($news) ?>.</p>

    <?php if (!$news): ?>
        <?php if ($q === ''): ?>
            <p>Новостей пока нет.</p>
        <?php else: ?>
            <p>По вашему запросу ничего не найдено. Попробуйте другое слово.</p>
        <?php endif; ?>
    <?php endif; ?>

    <?php foreach ($news as $item): ?>
        <article>
            <h3><?= e($item['title']) ?></h3>
            <p>Номер: <?= (int) $item['id'] ?>. Дата: <?= e($item['created_at']) ?></p>
            <p><?= nl2br(e($item['content'])) ?></p>
        </article>
    <?php endforeach; ?>
<?php endif; ?>
</body>
</html>

if (!$errors) скрывает результаты при ошибке. Сбой базы не превращается в сообщение «ничего не найдено».

count($news) считает строки, foreach перебирает их. $item['title'] и $item['content'] — поля очередной строки. (int) приводит id к целому числу.

nl2br(e(...)) сначала экранирует текст, затем добавляет HTML-переносы для новых строк. Порядок вызовов сохраняем именно таким. Безопасный вывод текста основан на htmlspecialchars() из PHP.

Контрольная остановка 3. Файл начинается с <?php, заканчивается </body> и </html>. Четыре блока идут подряд. Сохраните файл.

Шаг 3. Открыть страницу через сервер

Откройте тот же локальный сайт, где работает admin.php, заменив в адресе имя файла: 

http://site.local/news-search.php

Замените site.local своим доменом Open Server либо путём на localhost в XAMPP. Адрес file:///... не запускает PHP: открывайте страницу через HTTP.

Сначала должны появиться форма, количество новостей и список с большими id сверху. Введите Кружок, нажмите «Найти». В адресе появятся параметры q и sort; введённое слово останется в поле.

Чтобы увидеть HTTP-статус, откройте инструменты разработчика браузера, вкладку Network / Сеть. Выберите фильтр All / Все или Doc / Документ, затем отправьте форму. Найдите запрос news-search.php и посмотрите Status / Статус. Фильтр Fetch/XHR из лабораторной №7 здесь не подходит: мы загружаем целый HTML-документ.

Шаг 5. Небольшое самостоятельное задание

Под заголовком «Результаты», только при успешном запросе, добавьте понятное пояснение:

  • при пустом запросе: «Показаны все новости»;
  • при непустом запросе: «Поиск по заголовку: …», где вместо многоточия выводится введённое слово.

Подсказка: используйте $q === '' и e($q). SQL менять не требуется.

Критерии выполнения

Что оценивается Признак готовой работы
Поиск Строка ищется в title, пустая строка показывает все новости
Порядок new означает id DESC, old означает id ASC; произвольные значения не принимаются
Проверка ввода PHP отклоняет массивы, неверный порядок и запрос длиннее 100 символов со статусом 400
Работа с SQL Поисковое значение передаётся параметром PDO, порядок берётся из фиксированного списка
Вывод Данные и запрос экранируются; пустой результат и ошибка сервера различаются
Удобство Слово и выбранный порядок сохраняются, сброс условий работает
Понимание Студент может показать путь данных от формы до результата и объяснить три ключевые строки
