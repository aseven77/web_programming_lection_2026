Web-программирование. Лекция 3

PHP: циклы на практике

1. Зачем нужны циклы

На прошлой лекции мы разобрались с переменными, массивами и простыми функциями PHP. Но по-настоящему полезными скрипты становятся тогда, когда умеют автоматически обрабатывать много однотипных данных — список товаров, комментариев, пользователей, новостей. Именно для этого нужны циклы: конструкции, которые повторяют один и тот же блок кода для каждого элемента набора данных.

Сегодня разберём три вида циклов на одном сквозном примере — ленте новостей, а затем закрепим их ещё на паре простых задач.

2. Готовим данные: массив новостей

Представим, что у нас есть небольшая лента новостей. Пока без базы данных — просто массив массивов прямо в коде: 

<?php
$news = [
    ["title" => "Открылась новая библиотека", "views" => 120],
    ["title" => "Итоги олимпиады по программированию", "views" => 340],
    ["title" => "Расписание сессии обновлено", "views" => 980],
    ["title" => "Встреча выпускников факультета", "views" => 75],
];

Каждый элемент $news — это ассоциативный массив с двумя ключами: title (заголовок) и views (число просмотров). Такой набор данных прекрасно подходит для отработки циклов.

3. Цикл foreach: перебор новостей

foreach — самый удобный цикл для перебора массива, когда нам не важен числовой индекс, а нужен сам элемент. 

<?php
foreach ($news as $item) {
    echo $item["title"] . " — " . $item["views"] . " просмотров\n";
}

Результат:

Открылась новая библиотека — 120 просмотров
Итоги олимпиады по программированию — 340 просмотров
Расписание сессии обновлено — 980 просмотров
Встреча выпускников факультета — 75 просмотров

Если нужен ещё и порядковый номер новости, foreach можно совместить со счётчиком: 

<?php
$number = 1;

foreach ($news as $item) {
    echo $number . ". " . $item["title"] . "\n";
    $number++;
}

4. Цикл for: перебор по индексу

Цикл for удобен, когда важен именно числовой индекс элемента — например, чтобы вывести только первые три новости: 

<?php
for ($i = 0; $i < 3; $i++) {
    echo ($i + 1) . ". " . $news[$i]["title"] . "\n";
}

Здесь $i пробегает значения 0, 1, 2, а $news[$i] обращается к нужному элементу массива по индексу.

5. Цикл while: пока выполняется условие

while повторяет блок кода, пока условие в скобках остаётся истинным. Он полезен, когда заранее неизвестно точное число повторений.

Пример: выводим новости, пока не встретим первую с числом просмотров больше 500 (как будто ищем «горячую» новость): 

<?php
$i = 0;

while ($i < count($news) && $news[$i]["views"] <= 500) {
    echo $news[$i]["title"] . " (" . $news[$i]["views"] . ")\n";
    $i++;
}

echo "Нашли популярную новость: " . $news[$i]["title"];

6. Условие внутри цикла: выводим только популярные новости

Циклы часто комбинируют с условием if, чтобы отобрать только нужные элементы — это одна из самых частых задач на практике. 

<?php
foreach ($news as $item) {
    if ($item["views"] > 200) {
        echo $item["title"] . " — популярная новость!\n";
    }
}

7. Пример 2: подсчёт суммы и среднего

Циклы удобны и для вычислений над всем набором данных — например, посчитаем общее и среднее число просмотров всех новостей: 

<?php
$totalViews = 0;

foreach ($news as $item) {
    $totalViews += $item["views"];
}

$averageViews = $totalViews / count($news);

echo "Всего просмотров: " . $totalViews . "\n";
echo "В среднем на новость: " . round($averageViews, 1) . "\n";

8. Пример 3: собираем HTML-список новостей

На практике PHP чаще всего не просто печатает текст в консоль, а формирует HTML-разметку для страницы. Соберём из массива $news обычный HTML-список: 

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Лента новостей</title>
</head>
<body>
    <h1>Последние новости</h1>
    <ul>
        <?php foreach ($news as $item): ?>
            <li>
                <strong><?= $item["title"] ?></strong>
                (<?= $item["views"] ?> просмотров)
            </li>
        <?php endforeach; ?>
    </ul>
</body>
</html>

Здесь использован альтернативный синтаксис foreach (...): ... endforeach; — он часто применяется именно тогда, когда PHP-код перемежается с HTML-разметкой, так как без лишних фигурных скобок код читается удобнее. Конструкция <?= $item["title"] ?> — сокращённая запись <?php echo $item["title"]; ?>.

9. Итоги

  1. Циклы позволяют автоматически обрабатывать однотипные наборы данных — от новостной ленты до списка товаров или пользователей.
  2. foreach — основной цикл для перебора массивов, когда важен сам элемент, а не его номер.
  3. for — удобен, когда нужен точный контроль над числовым индексом (например, вывести только первые N элементов).
  4. while — повторяет действие, пока выполняется условие, и полезен, когда заранее неизвестно число повторений.
  5. Циклы часто комбинируются с условием if (отбор нужных элементов) и с накоплением значений в переменной (подсчёт суммы, среднего).
  6. Тот же самый foreach используется и для формирования HTML-разметки на странице — именно так на PHP строится вывод динамических списков.
