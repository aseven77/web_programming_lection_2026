# Лабораторная работа №2 (часть 2)

## Дисциплина: Web-программирование
## Тема: PHP — обработка формы и вывод JSON

---

## Цель работы

Научиться получать данные, отправленные пользователем через форму, и возвращать данные в формате JSON — как это делает простой backend для веб-приложения.

## Необходимые инструменты

- Локальный сервер с поддержкой PHP: **XAMPP**, **Open Server** или встроенный сервер PHP (`php -S localhost:8000`).
- Текстовый редактор или IDE (VS Code, PhpStorm).
- Браузер.

---

## Задание 1. Форма и обработка данных

1. Создайте файл `form.html` с формой из одного текстового поля `name` и кнопки отправки. Метод — `POST`, действие — `process.php`.
2. Создайте файл `process.php`, который:
   - получает значение поля `name` из `$_POST`;
   - выводит на страницу приветствие вида: *«Здравствуйте, Азамат!»*.
3. Добавьте функцию `htmlspecialchars()` при выводе значения `name` — это защищает страницу от подстановки постороннего HTML/JS-кода пользователем.

**Проверка:** введите в поле `name` текст `<b>тест</b>` и убедитесь, что на странице он выводится как обычный текст, а не как жирный шрифт.

---

## Задание 2. Простой вывод данных в формате JSON

1. Создайте файл `api.php`.
2. Заведите ассоциативный массив с данными об одном «товаре»: `name`, `price`.
3. Установите заголовок ответа:
   ```php
   header("Content-Type: application/json; charset=utf-8");
   ```
4. Выведите массив в формате JSON функцией `json_encode()`.
5. Откройте `api.php` в браузере и убедитесь, что страница показывает корректный JSON, например:
   ```json
   {"name":"Клавиатура","price":1500}
   ```
