# Лабораторная работа №3

## Дисциплина: Web-программирование
## Тема: Циклы в PHP на примере ленты новостей

---

## Цель работы

Научиться использовать циклы `foreach`, `for` и `while` для обработки массива данных на примере ленты новостей: выводить, отбирать и подсчитывать значения.

## Необходимые инструменты

- Локальный сервер с поддержкой PHP: **XAMPP**, **Open Server** или встроенный сервер PHP (`php -S localhost:8000`).
- Текстовый редактор или IDE (VS Code, PhpStorm).
- Браузер.

---

## Исходные данные

Во всех заданиях используйте один и тот же массив новостей — скопируйте его в начало каждого файла:

```php
<?php
$news = [
    ["title" => "Открылась новая библиотека", "views" => 120],
    ["title" => "Итоги олимпиады по программированию", "views" => 340],
    ["title" => "Расписание сессии обновлено", "views" => 980],
    ["title" => "Встреча выпускников факультета", "views" => 75],
    ["title" => "Стартовал набор в спортивные секции", "views" => 210],
];
```

---

## Задание 1. Вывод списка новостей (`foreach`)

Создайте файл `task1.php`.

1. С помощью цикла `foreach` выведите все новости построчно в формате:
   ```
   1. Открылась новая библиотека — 120 просмотров
   2. Итоги олимпиады по программированию — 340 просмотров
   ```
2. Порядковый номер новости выводите с помощью отдельной переменной-счётчика, которая увеличивается на каждом шаге цикла.

---

## Задание 2. Первые три новости (`for`)

Создайте файл `task2.php`.

1. С помощью цикла `for` выведите только первые три новости из массива (используйте индекс и обращение к элементу `$news[$i]`).
2. Формат вывода такой же, как в Задании 1.

---

## Задание 3. Поиск популярной новости (`while`)

Создайте файл `task3.php`.

1. С помощью цикла `while` пройдите по массиву новостей по порядку и выводите каждую новость, **пока** число просмотров не превысит 500.
2. Как только встретится новость с просмотрами больше 500 — выведите отдельным сообщением: *«Нашли популярную новость: …»* с её названием, и остановите цикл.

---

## Задание 4. Отбор популярных новостей

Создайте файл `task4.php`.

1. С помощью `foreach` и условия `if` выведите только те новости, у которых число просмотров больше 200, добавив к каждой пометку «— популярная новость!».
2. Посчитайте и выведите отдельной строкой, **сколько всего** новостей оказалось популярными (используйте переменную-счётчик).

---

## Задание 5. Общая и средняя статистика

Создайте файл `task5.php`.

1. С помощью цикла посчитайте суммарное число просмотров всех новостей.
2. Посчитайте среднее число просмотров на одну новость, округлив результат до одного знака после запятой (`round()`).
3. Выведите обе цифры на странице.

---

## Задание 6. HTML-список новостей

Создайте файл `task6.php`.

1. Оформите вывод новостей как настоящую HTML-страницу: заголовок `<h1>Лента новостей</h1>` и список `<ul>`, где каждая новость — отдельный пункт `<li>` с названием жирным шрифтом и количеством просмотров рядом.
2. Используйте альтернативный синтаксис `foreach (...): ... endforeach;`, как показано на лекции.

---

## Требования к оформлению отчёта

Отчёт оформляется в виде документа (`.docx` или `.pdf`) и должен содержать:

1. Титульный лист: ФИО студента, группа, тема лабораторной работы.
2. Листинги кода всех шести файлов.
3. Скриншоты результата работы каждого задания в браузере.

## Контрольные вопросы (для защиты работы)

1. Чем `foreach` отличается от `for` при переборе массива?
2. Когда удобнее использовать `while`, а не `foreach`?
3. Как остановить цикл раньше, чем он переберёт весь массив?
4. Как посчитать среднее значение по массиву чисел?
5. Для чего в HTML-коде используется запись `<?= ... ?>`?
