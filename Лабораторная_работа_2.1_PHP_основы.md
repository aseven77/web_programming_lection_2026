# Лабораторная работа №2 (часть 1)

## Дисциплина: Web-программирование
## Тема: PHP — переменные, массивы, условия и функции

---

## Цель работы

Научиться писать простые PHP-скрипты: работать с переменными, массивами, выводить данные на страницу, использовать условия, циклы и функции.

## Необходимые инструменты

- Локальный сервер с поддержкой PHP: **XAMPP**, **Open Server** или встроенный сервер PHP (`php -S localhost:8000`).
- Текстовый редактор или IDE (VS Code, PhpStorm).
- Браузер.

---

## Задание 1. Переменные и вывод данных

Создайте файл `task1.php`.

1. Объявите три переменные: `$name` (ваше имя, строка), `$group` (номер группы, строка), `$course` (курс обучения, число).
2. Выведите на страницу фразу вида: *«Меня зовут Азамат, я учусь в группе 41-ПИ на 4 курсе»*, используя вставку переменных в строку.

---

## Задание 2. Массив и цикл

Создайте файл `task2.php`.

1. Объявите индексный массив `$grades` из 5 оценок (числа от 2 до 5).
2. С помощью цикла `foreach` выведите каждую оценку на отдельной строке.
3. Посчитайте средний балл с помощью функций `array_sum()` и `count()`, округлите результат до двух знаков после запятой функцией `round()` и выведите его.

---

## Задание 3. Условие и функция

Создайте файл `task3.php`.

1. Напишите функцию `getGradeLabel($grade)`, которая по числовой оценке (2–5) возвращает текстовое описание:
   - `5` → `"Отлично"`
   - `4` → `"Хорошо"`
   - `3` → `"Удовлетворительно"`
   - `2` → `"Неудовлетворительно"`
2. Используя массив `$grades` из Задания 2 и функцию `getGradeLabel()`, выведите список вида:
   ```
   5 — Отлично
   4 — Хорошо
   3 — Удовлетворительно
   ```

---

## Требования к оформлению отчёта

Отчёт оформляется в виде документа (`.docx` или `.pdf`) и должен содержать:

1. Титульный лист: ФИО студента, группа, тема лабораторной работы.
2. Листинги кода всех трёх файлов.
3. Скриншоты результата работы каждого задания в браузере.
4. Краткий вывод по работе (2–3 предложения).
